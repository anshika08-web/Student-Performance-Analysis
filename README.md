# Student Performance Analysis and Prediction System

## Project Overview

The **Student Performance Analysis and Prediction System** is a Python
and machine-learning project that explores patterns in student study
habits and academic performance. It uses exploratory data analysis
(EDA), visualizations, and a Linear Regression model to estimate
examination scores from selected student-related features.

## Objectives

-   Explore the relationship between study habits and examination
    scores.
-   Summarize and visualize student performance data.
-   Examine correlations among selected numerical variables.
-   Train a Linear Regression model to predict `exam_score`.
-   Evaluate model predictions using MAE, RMSE, and R².

## Exploratory Data Analysis and Visualizations

The project includes five visualizations: 1. Average exam score by
study-hours group. 2. Distribution of students' exam scores. 3. Study
hours versus exam scores (scatter plot). 4. Box plot of students' exam
scores. 5. Correlation heatmap of student performance variables.

### Observations from the supplied graphs

-   The grouped bar chart shows higher average exam scores in the higher
    study-hours groups.
-   The scatter plot shows a positive relationship between hours studied
    and exam score, although individual scores vary.
-   The correlation heatmap shows a correlation of **0.78** between
    `hours_studied` and `exam_score`, and **0.43** between
    `previous_scores` and `exam_score`.
-   The heatmap shows weaker positive correlations of **0.19** for
    `sleep_hours` and **0.23** for `attendance_percent` with
    `exam_score` in this dataset.
-   The box plot and histogram summarize the spread and distribution of
    exam scores.

These are associations in the analyzed data; correlation does not
establish causation.

## Machine Learning

-   **Algorithm:** Linear Regression
-   **Target:** `exam_score`
-   **Input features shown in the correlation analysis:**
    `hours_studied`, `sleep_hours`, `attendance_percent`, and
    `previous_scores`
-   **Train/test split:** 80% training and 20% testing (as used in the
    project workflow; verify against the final notebook before
    submission).

## Model Evaluation

The following held-out test results were provided for this project:

  Metric                                        Result
  -------------------------------- -------------------
  Mean Absolute Error (MAE)           2.31085823589583
  Root Mean Squared Error (RMSE)      2.78599760743312
  R² Score                           0.853744713715951

MAE and RMSE are expressed in the target score's units. The R² value
indicates the proportion of variance explained by the model on the
evaluated test set; it is not an accuracy percentage.
